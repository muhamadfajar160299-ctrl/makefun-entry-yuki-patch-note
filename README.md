A one-line patch note announcing that human sleep is fixed, written to be funny
enough to make a reader laugh and plausible enough to sit in a real changelog.

## How it works

`main.py` (Python 3, standard library only) reads `entry.txt` next to it and
writes it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
python3 -S main.py
```
